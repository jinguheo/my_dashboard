# my-dashboard

Personal productivity dashboard with local MCP helpers for stocks, weather, RSS, AI news, PDF/web summaries, notes, calendar, backup/restore, and optional Mental Avatar integration.

## Quick Start

```bat
git clone <repo-url> my-dashboard
cd my-dashboard
install.bat
start_dashboard.bat
```

Open [http://localhost:5173](http://localhost:5173).

For full setup, restore, optional services, and troubleshooting, see [INSTALL.md](INSTALL.md).
